Python Quest is best on a laptop or desktop. On a phone, use the on-screen arrows to walk.

How Python Quest works

  1. 1You build the game by completing Python code blocks.
  2. 2Learn explains the idea, Run Code checks your answers, Fill Answer fills in the first blank of a block when you are stuck.
  3. 3Every block you finish unlocks part of the game.
  4. 4When the game is built, play it with the arrow keys and the battle buttons.
  5. 5Your progress saves in this browser. You can also copy a save code, or load one, at the bottom of the code blocks.
  6. 6Finish the game to unlock creator mode.
